# Globe Trek - Sri Lanka Travel Booking System

PHP + MySQL travel booking website (customer, staff and admin portals).

## Setup
1. Install XAMPP, copy this folder into `htdocs/`.
2. Create a database `globe_trek` in phpMyAdmin and import `globe_trek.sql`.
3. Copy `db_connect.example.php` to `db_connect.php` and set your DB details.
4. Open `http://localhost/globe_trek/Homepage.html`.
5. Register a user, then set its role to `admin` in the `users` table.
